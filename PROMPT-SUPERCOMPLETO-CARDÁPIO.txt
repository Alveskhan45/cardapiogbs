9. LÓGICA DE BUSCA - ESTADO "ÓTIMO" (NÃO MEXER)
================================================================================
ARQUIVO: public/js/menu.js (linhas ~15-28)

    function norm(s) {
      return String(s || '')
        .normalize('NFD').replace(/[\u0300-\u036f]/g, '')  // remove acentos
        .replace(/ç/g, 'c')                                 // ç → c
        .toLowerCase();
    }

    function productMatches(p, q) {
      if (!p.active) return false;
      if (!q) return true;
      const terms = norm(q).split(/\s+/).filter(Boolean);
      const hay = norm(p.name);          // APENAS NOME (não descrição)
      return terms.every(t =>
        hay.split(/\s+/).some(w => w.startsWith(t))   // PREFIXO, não includes
      );
    }

REGRAS IMUTÁVEIS:
  1. Busca fonte: APENAS p.name (nunca desc, categoria, extras)
  2. Algoritmo: PREFIXO de palavra (w.startsWith(t)), nunca includes/contains
  3. Mínimo: 1 letra (sem restrição de tamanho)
  4. Multi-termos: AND (todos os termos devem casar)
  5. norm(): remove acentos, ç→c, lowercase
  6. Produto inativo (active=false): nunca aparece em busca
  7. Admin usa EXATAMENTE a mesma productMatches:
     renderAdminProducts: list.filter(p => productMatches({...p, active:true}, q))

11. LÓGICA DE PREÇOS (NÃO PODE MUDAR)
================================================================================
calcItemPrice(item, base) - igual em cart.js:8-13 E server.js:316-321:

    const vPrice = variation ? variation.price : null;
    const finalBase = vPrice !== null ? vPrice : base;   // Variação = PREÇO ABSOLUTO
    return finalBase + extrasSum;                         // Extras = DELTA (soma)

REGRAS:
  1. Variação de preço é ABSOLUTO (substitui o preço base), nunca delta

19. FLUXOS DE AÇÃO - PASSO A PASSO
================================================================================

19.1 ADICIONAR CATEGORIA
    Clique "+ Nova" → addCategory() → overlayCategory (vazio)
    → usuário digita nome+emoji → saveCategory()
    → valida (obrigatório, não duplicado) → state.categories.push
    → logActivity ➕ → save() → renderCategories+renderCats+renderAdminProducts
    → fecha modal → toast "✅ Categoria salva"

19.2 EDITAR/RENOMEAR CATEGORIA
    Clique [data-rencat] → editCategory(old) → overlayCategory (preenchido)
    → usuário altera → saveCategory()
    → se mudou nome: state.categories[idx]=name + atualiza p.category dos produtos
    → logActivity ✏️ → save() → renders → toast

19.3 EXCLUIR CATEGORIA
    Clique [data-delcat] → showConfirm("Excluir X?") → confirmOk
    → remove da lista (produtos ficam com categoria órfã - verificar comportamento)

19.4 BUSCA NO CARDÁPIO
    digita → renderCats → productMatches para cada produto de cada categoria
    → categorias com match vão topo e abrem; sem match vão base e fecham
    → exibe contagem de resultados

19.5 LOGIN ADMIN
    botão admin → overlayLogin → senha → POST /api/login
    → compara hash → openAdminPanel() → connectEvents() (SSE+Notification)
    → localStorage marca admin unlocked

19.6 CRIAR PEDIDO (cliente)
    adiciona itens → carrinho → checkout → dados+bairro+pagamento
    → POST /api/orders → grava em db.json → overlaySuccess (código+wa+QR)

19.7 ALTERAR SENHA
    admin tab seg → nova senha → POST /api/admin/password
    → server gera hash → salva em config.adminPasswordHash
